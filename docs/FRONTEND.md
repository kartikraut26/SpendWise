## UI Guidelines

SpendWise will use a consistent Glassmorphism visual style:

- Semi-transparent surfaces
- Background blur
- Subtle borders
- Rounded corners
- Soft shadows
- Consistent spacing
- Responsive layouts

Tailwind utility classes should be preferred over scattered custom CSS.

## Frontend Rule

Feature-specific components should remain inside their feature/module where practical. Shared components belong in the common components area and should be reusable by all members.
